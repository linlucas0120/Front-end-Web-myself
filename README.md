# 金庫防爆特攻隊

長輩友善的防詐練習網站，使用原生 HTML、CSS 與 JavaScript ES Modules，無執行期套件。

[開啟網站](https://ymhs0208.github.io/Front-end-Web-Development-Course/)

## 本機啟動

在本專案資料夾執行，不需要 `npm install`：

```sh
python3 -m http.server 5173 --directory dist
```

開啟 [本機網站](http://localhost:5173)。請使用 HTTP 伺服器，直接雙擊 HTML 可能無法載入 JavaScript 模組。

## 目前功能

- 首頁直接說明「認識詐騙，保護你的錢」，首頁內容最前方提供唯一主要開始卡片，以播放圖示、「開始練習」與「每次 3 題」說明操作；下方提供選練習主題、我的獎勵與操作說明。
- LINE 題庫保留原始九題資料，目前練習只開放第 1、5、9 題；可依序練習三題或隨機挑戰這三題。第 1 題有模擬假網站與預填回覆流程；第 5 題可互動模擬螢幕共享警示或掛斷來電；第 9 題呈現高薪求職詐騙，並提供不連外、不收款的仿電子支付頁，點選模擬付款會顯示警示，拒付後可回聊天室選單封鎖。每場從 NT$400 開始，選錯答案扣 NT$100；金額歸零會顯示「你的現金被騙光了！！」提醒。另有「熟人換新帳號借錢」互動分支，共用相同的金錢規則，並依玩家選擇進入不同後續。
- 獨立作答頁，顯示剩餘金額，答錯時會有扣款動畫；依序選答案、看解說、進入下一題。完成後顯示剩餘金額及星星鼓勵，按「看獎勵」查看收集成果。
- 四級字體與國語／台語／客語朗讀；新訪客預設特大字，特大／最大模式提供分段閱讀。頁首可按「朗讀」聽操作提示，題目可朗讀本段。
- 每完成 1 題就獲得 1 顆安心星，答錯、重複練習都算，無累積上限；3 顆星讓夥伴披上披風，9 顆星戴上皇冠。勳章依不同情境解鎖；有錯題時可按「再練一次」複習。
- 電腦與手機排版；頁首採簡潔工具列，提供回首頁的網站名稱、字體與語音設定；頁尾僅保留品牌首頁與使用說明。

逐題紀錄與完成的分支路徑保存在目前瀏覽器，不跨裝置同步，也不會送到伺服器；清除瀏覽資料會移除紀錄。國語使用裝置語音；台語使用外部 model6 TTS，客語使用 Hugging Face 的臺灣客語語音合成系統，皆需連線且受服務流量限制。台語、客語朗讀文字會送到外部服務，不包含作答紀錄；合成發音可能不完全自然。情境均為防詐教育示範。介面尚未經長輩真人試用。

熟人換新帳號借錢情境依常見防詐原則設計。已匯款後的建議參考[刑事警察局：把握黃金時間撥打 165](https://www.cib.npa.gov.tw/ch/app/news/view?id=1887&module=news&serno=4e55ed31-dba5-475a-9098-b8c1bad1c919)及[警政署 165 諮詢、檢舉與報案資訊](https://www.npa.gov.tw/ch/app/faq/view?module=faq&id=2144&serno=A1078837)；及早聯絡有機會協助攔阻，但不保證款項一定追回。

## 檢查

需安裝 Node.js，無須安裝測試套件：

```sh
npm run check
npm test
```

檢查涵蓋 JavaScript 語法、匯入路徑、循環依賴，以及一般出題、分支路徑、會話還原、閱讀分頁和獎勵規則。

## 台語朗讀

上方「自動朗讀」可選不自動、國語、台語或客語，設定會保存。「不自動」只停止自動播放，手動朗讀仍使用上次選擇的語言，初次使用為國語。台語沿用 [Taiwanese-tts Space](https://huggingface.co/spaces/tbdavid2019/Taiwanese-tts/blob/main/app.py) 使用的公開 model6 API，直接從瀏覽器呼叫 `https://learn-language.tokyo/taigiTTS/taigi-text-to-speech`，不需金鑰或新增後端。音檔由服務回傳的 HTTPS 網址播放。

播放同文時使用本次開啟的快取（最多 32 段），重整後重新產生。可在準備中或播放時停止；換頁會取消等候及播放。45 秒未完成時提示稍後重試；API 限流或網路失敗不會自動改成國語。部分手機需要在音檔準備完成後再按一次朗讀。

台語服務模組：`dist/js/features/taiwanese-tts.js`；語音介面：`dist/js/features/accessibility.js`。國語與台語共用 `say`、`stopSpeech`、`isSpeaking`，新頁面不應直接操作 SpeechSynthesis。

## 客語朗讀

上方「自動朗讀」選客語，使用 [臺灣客語語音合成系統](https://huggingface.co/spaces/united-link/taiwanese-hakka-tts) 的公開 Gradio `/text_to_speech` API。固定模型 `yourtts-htia-240704`、四縣腔（`sixian`）、預設語者朱品諭，語速參數 1.1。無需錄音或上傳個人聲音。

客語是依輸入文字合成發音，沒有額外翻譯國語文法。引擎不接受阿拉伯數字，因此僅在朗讀內容中將數字、金額和百分比轉成中文讀法，並略去不發音的引號，將發話者標點轉為停頓；畫面題目不變。無法辨識的字詞或服務忙碌時會提示重試或改選國語，不會假裝成功或自行切換語言。

使用 POST 建立合成工作，再以串流讀取音檔結果；等候上限 90 秒。停止、換頁或切換語言時會中斷瀏覽器等候及播放；已送出的伺服器工作不保證同時終止。客語與台語各有最多 32 段音檔網址快取，重新開啟後清空。手機若阻擋自動播放，準備完成後會顯示「播放語音」，再按一次即可。

`hakka-tts.js` 處理客語格式與串流；`taiwanese-tts.js` 處理台語 API；`remote-speech.js` 共用取消、快取、逾時與音檔播放邏輯。三者位於 `dist/js/features/`。

## 星星規則與舊紀錄

星星直接由有效的已作答紀錄計算，每筆紀錄 1 顆，不因答案正誤或題目重複而減少。原有紀錄自動換算，不修改儲存格式或清除歷史；過去曾重練的使用者可能看見星星數增加。開啟獎勵頁或重新整理不會另加星，重整還原已作答頁也不重複記錄。每次三題完成畫面會顯示「獲得 3 顆安心星」。

夥伴成長條上的 9 顆星代表戴皇冠的門檻，累積星數可繼續超過 9。勳章依不同題目、情境類型判斷，重複同題不會解鎖「完成全部情境」勳章。

## 配色

共用主題位於 `dist/css/theme.css`，最後載入。淺紫背景 `#F5EEFF`、紫色主按鈕 `#804FC0`，其餘入口和卡片使用白底、淡紫圖示與深色文字。次要操作及返回按鈕使用白底描邊，讓主要操作保持醒目。獎勵星星保留金色，作答狀態保留語意提示。
